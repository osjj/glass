## 关键问题与修正

| 原文问题 | 已落实的修正 |
| --- | --- |
| 把 neck finish 定义为 TPI | 改为瓶口与闭合件配合部位及完整规格；要求型号、图纸、密封面和公差，不能只按直径或数螺纹判断 |
| 固定写 70 mm / 2-thread (400)、86 mm / 3-thread (450) | 删除未经支持的对应关系；400 等是规格语境中的代码，不是 TPI。regular/wide mouth 也不能代替实际盖罐匹配确认 |
| nominal capacity 一律等于装满至溢口的容量 | 区分 nominal、brimful/overflow、目标装量与 headspace，并要求供方注明口径 |
| 按 85–90% 或除以 0.88 统一选罐 | 删除统一系数；改为实际内容物装填试验与适用工艺要求 |
| “500 mL net-weight product”混淆重量与体积 | 明确 mL 是体积、g 是质量，500 g 不能直接转成所需罐体积；颗粒物还受堆积、沉降影响 |
| 容量 ±3–5% 并建议 PO 固定 ±5% | 删除通用公差，按型号、测量方法和供方能力约定 |
| two-piece metal 写成 band + lug | 改为 flat sealing lid/disc + screw band，并用独立零件配图说明 |
| 单片式金属 lug 盖一律不能真空、只能干货 | 用 Silgan 具体产品说明存在热灌装/巴氏处理及真空按钮配置；不把个别产品能力泛化为所有金属盖 |
| clamp、塑料盖一律 airtight，木盖一律不密封 | 改为整套盖、密封件与罐身验证；闭合、气密、漏液、真空及保质期分别确认 |
| 硅胶是统一标准、天然橡胶便宜但劣化更快等 | 删除材料优劣泛化；要求具体配方、接触条件、护理和适用文件 |
| 按干湿用途简单判定金属盖与内衬食品安全 | 改为玻璃、涂层、盖、内衬、垫圈等完整食品接触系统，按内容物、温度、时间和目的地核对 |
| 固定 1,000/5,000/10,000/20,000 价格档、15–25% 折扣、20–35% 盖成本 | 删除无出处比例，要求真实分档报价；不建议为了折扣盲目加单 |
| 固定罐重及“单价差 5% 落地差 15–20%” | 删除无出处数字，按实际重量、包装和运费报价核算 |
| 强调按每托盘价格比较，但不统一每托盘件数 | 补充“同口径总到货成本 ÷ 可用完整套件数”，标明费用和损耗假设 |
| 固定箱规、分隔材料与区域托盘尺寸 | 改为实测包装、托盘尺寸和装载计划；不将一个区域名称视为唯一规格 |
| 一次 1 m 跌落、标准洗碗/灭菌循环作为通用验收 | 删除，改为适用运输测试及具体产品护理；洗碗试验不是食品保存工艺验证 |
| 漏液或抽真空成功容易被理解为可安全常温保存 | 明确罐、盖、食品和工艺的验证边界，区分家庭罐藏指引与商业加工要求 |
